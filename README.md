# Roaring Twenties Jeopardy

A Jeopardy-style review game for a U.S. History Roaring Twenties unit (Texas TEKS-aligned), with team scoring, two Daily Doubles, a 20-second answer timer, and built-in sound effects (no audio files needed — all sounds are synthesized in the browser).

## Play it online
Once GitHub Pages is turned on for this repo (Settings → Pages → Deploy from branch → `main` / root), the game will be live at:

https://jimmaoscott-lang.github.io/roaringtwentiesjeporady/

## Play it locally
Just open `index.html` in any browser. No install, no build step.

## Categories
- Boom Times (1920s economy & consumerism)
- Culture & Harlem (Jazz Age, Harlem Renaissance)
- Red Scare & Nativism (immigration quotas, KKK, Scopes Trial)
- New Media & Tech (radio, automobile, aviation, film)
- Texas in the Twenties (oil boom, Ma Ferguson, cotton)

## Editing questions
All clues live near the top of `index.html` in a `CATEGORIES` array — edit the text there to change or add questions.
